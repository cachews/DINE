# DINE: Dual Intermittent Network

Reference implementation for algorithm described in [DINE: Dual Intermittent Network for Intermittent Demand Forecasting]()

## Requirements

Install the required packages with

```
pip install -r requirements.txt
```

## Data

Download the M5 competition data from [Kaggle](https://www.kaggle.com/competitions/m5-forecasting-accuracy) and extract files in `./dataset/M5/`

## Usage

Run the example script from

```
./scripts/dine-example.sh
```
